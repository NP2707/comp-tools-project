This is a descriptive pilot with independent exhaustive retrieval evaluation. `data/manifest.json` and each run's `summary.json` record data/code checksums and configuration.

The [dataset documentation](https://github.com/giuseppedestefanis/gitskills-sample) distinguishes file occurrences from distinct contents. We analyze content groups, retaining occurrence and repository counts. Text comes from the primary row and is verified using Git's blob hash. The default population requires an uppercase `SKILL.md` occurrence, valid frontmatter, nonempty name and description, and at least 30 body tokens. Occurrence totals include all copies of an eligible content, even under other filenames. These are operational filters, not quality labels. Content-hash sampling does not ensure that every variant of a near-duplicate family is present.

Normalization strips delimited leading YAML, applies Unicode NFKC and case folding, and extracts Unicode word tokens including numbers and underscores. Body prose and code examples remain. No stemming, stopword removal, or length truncation is used. Five-word shingle sets preserve local order and count each distinct shingle once. `--keep-frontmatter`, `--include-nonstandard`, and `--shingle-size` allow sensitivity runs.

Custom MinHash uses 128 seeded affine hashes modulo 4,294,967,291. Shingles are first mapped with a stable 32-bit BLAKE2 digest; intermediate arithmetic fits uint64. These are approximately minwise hashes, not uniformly sampled permutations of all strings. Chunking bounds temporary arrays. LSH proposes pairs sharing a band; defaults are 32 bands of four rows. Under the ideal independent-MinHash model, candidate probability is `1 - (1 - s**r)**b` for similarity `s`, `b` bands, and `r` rows.

Verification uses the original shingle strings, so hash collisions cannot create false verified edges. The set-size ratio provides an exact upper bound for early rejection. The main threshold is 0.8. An explicit two-million-candidate cap fails visibly instead of silently dropping buckets.

The weighted graph has one node per original content, no self-loops, exact Jaccard edge weights, and retained isolates. [Louvain](https://networkx.org/documentation/stable/reference/algorithms/generated/networkx.algorithms.community.louvain.louvain_communities.html) uses a fixed seed. Sensitivity tables compare resolutions 0.5, 1, and 2 at thresholds 0.6–0.9. Modularity is a graph property, not semantic validation. Communities can contain endpoints below the pairwise threshold; sparse graphs may yield only connected components and give little evidence that community detection adds value.

Evaluation selects documents uniformly with a separate seeded random stream, then checks every unordered pair within that subset. Evaluation pairs are never selected using LSH. Ground truth is exact lexical Jaccard. Layouts 16×8, 32×4, and 64×2 are compared using independently computed subset signatures. Metrics include recall, missed pairs, candidate precision, verified precision, candidate reduction, and runtime. Zero-positive recall is undefined. Verified precision is one by construction and does not measure human agreement. Layout timings include signatures and verification at the lowest threshold; they are shared across threshold rows. Single-run timing and subset recall do not establish full-corpus performance.

The outside-course technique is [LSA](https://scikit-learn.org/stable/modules/generated/sklearn.decomposition.TruncatedSVD.html): sublinear TF-IDF, minimum document frequency two, at most 30,000 terms, and randomized truncated SVD with up to 64 components. Cosine similarity compares normalized projections. Each document contributes up to five neighbours with cosine >= 0.8; their undirected union forms the candidate set. Absence from this set need not mean low cosine because of the top-k cap. LSA is fit on the selected corpus for exploration; no held-out predictive quality is claimed.

The review queue samples up to 12 pairs from each of three sets: both methods, lexical only, and LSA only. It records stratum sizes and leaves reviewer labels blank. Agreement between representations is not validation. Boilerplate, language effects, filtering, seed stability, stronger novelty, and human assessment remain research work.

Dataset instructions are treated as text, never executed. Similarity in a snapshot cannot establish copying direction, authorship, intent, or quality. Conference reporting should emphasize aggregate structure; inspect review artifacts before public release.
